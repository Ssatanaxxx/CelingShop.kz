## ✨ Особенности

### 🎨 Дизайн & UX
- **Современный минималистичный дизайн** с акцентами на желтом
- **Полная адаптивность** (Mobile-first подход)
- **Плавные анимации** и переходы
- **Интуитивная навигация** с sticky header
- **Оптимизированная производительность** (Lighthouse score > 90)

### 💻 Технические особенности
- **TypeScript** для типобезопасности
- **SCSS Modules** для изолированных стилей
- **React Hooks** (useState, useEffect, useCallback)
- **Кастомные хуки** для повторной логики
- **Оптимизированные изображения** (WebP с fallback)
- **Доступность (a11y)** соблюдены WAI-ARIA стандарты

### 📱 Адаптивность
- **320px** - Мобильные телефоны
- **425px** - Большие телефоны
- **768px** - Планшеты
- **1024px** - Ноутбуки
- **1440px+** - Десктопы и 4K мониторы
